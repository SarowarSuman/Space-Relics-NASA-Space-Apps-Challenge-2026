# 🌌 Abandoned but not Forgotten

### An Interactive Story of NASA's Discarded Equipment on the Moon and Mars

> Since the 1960s, NASA's missions to the Moon and Mars have left behind equipment, scientific instruments, and robotic explorers. Though many are no longer active, each object represents a chapter in humanity's journey into space.

**Abandoned but not Forgotten** is an interactive storytelling website that explores the history and significance of human-made objects left behind on the Moon and Mars. It combines space exploration, visual storytelling, and interactive experiences to reveal the stories behind these forgotten relics.

## 🚀 Project Overview

The project presents space exploration through an immersive digital experience. Visitors can explore abandoned equipment, learn about lunar and Martian missions, compare objects and mission details, and discover how these relics contribute to the history of space exploration.

Rather than treating these objects as ordinary debris, the website presents them as reminders of scientific discovery, human achievement, and the challenges of exploring other worlds.

## ✨ Features

- **🌐 3D Explorer** — Explore a visual space environment featuring celestial bodies and abandoned equipment.
- **🌕 Moon Exploration** — Discover equipment and objects left behind by lunar missions.
- **🔴 Mars Exploration** — Explore robotic explorers and mission-related relics on Mars.
- **🚦 Mission Status** — Explore the status and history of selected space equipment.
- **⚖️ Compare** — Compare selected objects and their mission-related information.
- **⏱️ Lifetime** — Explore the operational history and lifespan of space equipment.
- **🚀 Deep Space** — Navigate the broader context of space exploration.
- **🧠 Interactive Quiz** — Test knowledge of space missions and abandoned equipment.
- **📊 Mission Statistics** — View key figures related to lunar landings, astronauts, Mars rovers, and mission leftovers.
- **🎨 Immersive Visual Design** — Experience a dark space-themed interface with 3D-inspired visuals and interactive elements.

## 🎯 Project Objectives

- Raise awareness of human-made objects left behind during space exploration.
- Present the history of lunar and Martian missions through interactive storytelling.
- Explain the scientific and historical significance of abandoned space equipment.
- Make space exploration history more engaging and accessible to a wider audience.
- Encourage curiosity about humanity's presence beyond Earth.

## 💻 Run Locally

The website can be opened locally in a web browser.

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/space-relics.git
   ```

2. Open the project folder:

   ```bash
   cd space-relics
   ```

3. Open `index.html` in a web browser.

4. Navigate through the available sections and interact with the website's features.

If the project uses external libraries or services, an internet connection may be required for those resources to load.
